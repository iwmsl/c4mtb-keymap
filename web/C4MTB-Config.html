USB接続とファームウェアの更新方法

WindowsのChromeまたはEdgeで、HTTPSのURLかダウンロードしたHTMLを開きます。右手側をデータ通信対応のUSBケーブルでつなぎ、以前に使っていた設定アプリを閉じてから「USBで接続」を押してください。

ファイルで編集した設定は、書き出した c4mtb.keymap を GitHub の config/c4mtb.keymap に反映し、Actions が生成した通常版の c4mtb_R.uf2 を右手側に書き込みます。右手側のブートローダーはリセットボタンの2回押しで起動できます。

USBでコンボを編集するには、右手側にコンボ対応版の c4mtb_R_usb_combos.uf2 を一度書き込みます。USB編集で保存したコンボは、本体で使う設定です。

本体のキーマップをUSBで保存したことがある場合、ファームウェアの既定配列よりUSBで保存した割り当てが優先されます。コンボだけ編集する場合は、GitHub上の最新の .keymap を開いて編集すると、ファイル側のキー割り当ても引き継げます。
