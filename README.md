# C4MTB keymap

C4MTB のキーマップ編集専用リポジトリです。

## 編集方法

[customkeymap](https://customkeymap.com/) の GitHub 入力欄に `iwmsl/c4mtb-keymap` を入力し、Load を押してください。

- `config/c4mtb.keymap`: ZMK キー割り当て・レイヤー・コンボ
- `config/info.json`: GUI 用の物理レイアウト

ここではキーマップの編集のみを扱います。ファームウェアのビルドや実機への書き込みには、ファームウェア側への変更の反映が別途必要です。
